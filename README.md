# SoftOS OTA

Update list for **SoftOS**, an unofficial LineageOS-based ROM for the Xiaomi 17 Pro Max (`popsicle`).

The built-in **Settings › System › Updater** reads `popsicle.json` from this repository to find new
SoftOS versions. Update packages themselves are downloaded from the project's file hosting, not
from this repository.

- Telegram channel: https://t.me/softosrom
- Each update is a signed A/B OTA package; only packages signed with the SoftOS release keys can be installed.

---

**Türkçe:** Bu depo, telefondaki **Ayarlar › Sistem › Güncelleyici**'nin yeni SoftOS sürümlerini
bulmak için okuduğu sürüm listesini (`popsicle.json`) içerir. Güncelleme paketleri buradan değil,
projenin dosya sunucusundan indirilir. Duyurular: https://t.me/softosrom
